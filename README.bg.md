# ESP32-C5 Custom Bruce Firmware

🌍 [English](README.md) · **Български**

[Bruce](https://github.com/pr3y/Bruce) firmware, пренесен на **ръчно свързан
Waveshare ESP32-C5** с външен **ST7789V** дисплей и **KEYES аналогов джойстик**.
Репото съдържа board дефиницията, нужните патчове, инструкции за билд/флаш и
готов за флашване binary.

📖 **Нов си? Започни с [урока стъпка по стъпка](TUTORIAL.bg.md)** · [Tutorial in English](TUTORIAL.md)

> ESP32-C5 е съвсем нов RISC-V чип с двубандов Wi-Fi 6. Подкарването на Bruce на
> ръчно свързан C5 изисква няколко неочевидни поправки (дисплей, вход, стабилност) —
> всички документирани тук, за да може всеки със същите части да ги повтори.

## Хардуер

| Част | Модел |
|------|-------|
| Платка | **Waveshare ESP32-C5-WiFi6-KIT** (16 MB flash, **без PSRAM**) |
| Дисплей | **Waveshare 2" LCD Module — ST7789V, 240×320, SPI** |
| Вход | **KEYES аналогов джойстик** (X/Y + бутон) |
| Захранване | 3.8 V LiPo + ключе на плюса (по избор) |

Пълно свързване и пинове: **[docs/connections.md](docs/connections.md)**

Бърз пинов преглед:
- **Дисплей:** MOSI=IO23, SCLK=IO24, CS=IO10, DC=IO9, RST=IO8, BL=IO0
- **Джойстик:** X=IO1, Y=IO4, BTN=IO5, VCC=IO6 (от GPIO), GND=GND

## Управление

| Действие | Джойстик |
|----------|----------|
| Навигация | Горе / Долу |
| **Избор / OK** | **Надясно**, или натисни в средата |
| **Назад** | **Наляво**, или задръж средата |
| Клавиатура | 4 посоки движат, кратко = пишеш, задържане = готово |

## Флашни готовия firmware

```bash
ls /dev/cu.usbmodem*        # macOS      (Linux: ls /dev/ttyACM*)
pip install esptool
esptool --chip esp32c5 -p PORT write-flash 0x0 firmware/Bruce-esp32-c5-joy.bin
```

Ако не се свързва: задръж **BOOT**, натисни **RST**, пусни **BOOT**, после флашни.

## Билд от сорс

```bash
./setup.sh          # клонира Bruce + слага board файловете + патчовете
cd bruce
pio run -e esp32-c5-joy
```

Нужен е [PlatformIO](https://platformio.org/).

> **Бележка:** `setup.sh` закотвя Bruce на commit `ba519c93` и FastLED на 3.10.3 —
> по-новите чупят билда на C5 toolchain-а (fixed-point/FFT грешки).

## Какво кара този board да работи (поправките)

1. **Без PSRAM** — C5 модулът няма; `BOARD_HAS_PSRAM` НЕ е дефиниран, иначе boot-loop.
2. **Display force-route** — TFT_eSPI пише пиксели през директни SPI регистри, които
   стигат панела само на FSPI IOMUX пиновете. Дисплеят е на GPIO-matrix пинове, затова
   `_pre_storage_gpio()` закача FSPI CLK/DATA на IO24/IO23 и пре-изпраща ST7789 init-а.
3. **Soft-RST поправка** — хардуерен reset импулс + SWRESET при всяко пускане, за да
   преинициализира панела при натискане на RST (без да вадиш захранването).
4. **Устойчив джойстик** — авто-калибрация, отхвърляне на GND-грешки, edge-only
   навигация (едно бутане = една стъпка). Бутонът е active-HIGH; кратко = Избор, дълго = Назад.
5. **Екранна клавиатура** — board-ът дефинира `HAS_5_BUTTONS` (иначе клавиатурата
   забива), с `joyKbdMode` флаг — менютата пазят Ляво=Назад/Дясно=Избор, клавиатурата получава чисти 4 посоки.
6. **Авто-възстановяване от crash-loop** — при 3 рестарта преди UI-то (напр. лоша
   конфигурация от Evil Portal) сам трие NVS + LittleFS и тръгва чисто — без компютър.

## Бележки и ограничения (специфики на C5)

- **Няма кабелен USB BadUSB** — C5 няма USB-OTG. Ползвай **Bad BLE** (Bluetooth),
  или добави **CH9329** модул за кабелен USB HID.
- **Sub-GHz / 2.4 GHz jam / NFC** искат външни модули (CC1101 / NRF24 / PN532) на
  свободните пинове (IO2, IO3, IO7, IO25, IO26, IO28).
- WiFi и Bluetooth/BLE функциите ползват вграденото радio на C5 — без модул.
