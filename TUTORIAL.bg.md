## 1. Какво ще сглобиш

Джобен пентест/хакерски мултитул с [Bruce](https://github.com/pr3y/Bruce):
WiFi атаки (deauth, evil portal, beacon spam), Bluetooth/BLE (BLE spam, Bad BLE
= безжичен BadUSB), уеб интерфейс, скриптове и още — управляван с джойстик на 2" екран.

## 2. Какво ти трябва

| Част | Модел |
|------|-------|
| Платка | Waveshare **ESP32-C5-WiFi6-KIT** (16 MB, без PSRAM) |
| Дисплей | Waveshare **2" LCD Module — ST7789V, 240×320, SPI** |
| Вход | **KEYES аналогов джойстик** (X/Y + бутон) |
| Кабели | Dupont женски-женски |
| (по избор) | 3.8 V LiPo + ключе ≥1 A на плюса на батерията |

## 3. Свързване

Свържи с жички (номерата са GPIO):

**Дисплей (ST7789V):**
`VCC→3V3, GND→GND, DIN→IO23, CLK→IO24, CS→IO10, DC→IO9, RST→IO8, BL→IO0`

**Джойстик (KEYES):**
`X→IO1, Y→IO4, B→IO5, VCC→IO6, GND→GND`

> ⚠️ **GND на джойстика трябва да е здрава спойка.** Хлабав GND кара двете оси да
> четат високо и менюто се чуди. Firmware-ът го търпи, но здрава спойка е най-добре.

Пълна таблица: [docs/connections.md](docs/connections.md).

## 4. Инсталирай PlatformIO

```bash
pip install platformio      # или разширението PlatformIO за VS Code
```

## 5. Компилирай firmware-а

```bash
git clone https://github.com/gpsn0w/esp32-c5-custom-bruce-firmware
cd esp32-c5-custom-bruce-firmware
./setup.sh                  # клонира Bruce (закотвен) + прилага патчовете
cd bruce
pio run -e esp32-c5-joy
```

Готовият образ е `Bruce-esp32-c5-joy.bin`.
**Не искаш да компилираш?** Ползвай готовия `firmware/Bruce-esp32-c5-joy.bin`.

## 6. Флашване

```bash
ls /dev/cu.usbmodem*        # macOS   (Linux: ls /dev/ttyACM*)

esptool --chip esp32c5 -p PORT write-flash 0x0 firmware/Bruce-esp32-c5-joy.bin
```

Ако не се свързва: задръж **BOOT**, натисни **RST**, пусни **BOOT**, после флашни.

## 7. Първо пускане и управление

Натисни **RST** — трябва да видиш менюто на Bruce.

| Действие | Джойстик |
|----------|----------|
| Навигация | Горе / Долу |
| **Избор / OK** | **Надясно**, или натисни в средата |
| **Назад** | **Наляво**, или задръж средата |
| Клавиатура (пишеш текст) | 4 посоки движат, кратко натискане пише, задържане = готово |

> Съвет: задръж стика мирно ~1 сек при пускане — тогава се калибрира центърът.

## 8. Пробвай първо тези (безплатно, вградено радio)

- **WiFi → Wifi Atks → Deauth** — разкача устройства от **твоята** мрежа.
- **Bluetooth → BLE Spam** — залива близки телефони с фалшиви BLE pop-up-и.
- **Bluetooth → Bad BLE** — избираш `.txt` скрипт, сдвояваш целта по Bluetooth, набира скрипта (това е „BadUSB" по Bluetooth — C5 няма USB-OTG за кабелен BadUSB).
- **Files → WebUI** — файлове през браузър (`http://172.0.0.1`).

## 9. Разширяване (свободни GPIO: IO2, IO3, IO7, IO25, IO26, IO28)

- **CC1101** → sub-GHz (433 MHz гаражи/дистанционни) — RF меню.
- **PN532** → NFC/RFID (аксес карти, домофонни ключове, Amiibo) — I²C, само 2 пина.
- **NRF24L01+** → 2.4 GHz jam / MouseJack.
- **CH9329** → кабелен USB BadUSB (понеже C5 не може сам).

## 10. Решаване на проблеми

- **Свети, но черен екран** → FSPI force-route го оправя; хардуерен RST импулс
  преинициализира панела, затова просто натисни **RST**.
- **Менюто се върти самó** → хлабав GND на джойстика; този билд е edge-triggered,
  затова дрейфът дава най-много една стъпка. Пре-запои GND за идеал.
- **Boot-loop след дадена функция (напр. Evil Portal)** → firmware-ът
  **сам се възстановява**: след 3 рестарта трие лошата конфигурация и тръгва чисто. Без компютър.
- **BadUSB не набира** → ползвай **Bad BLE** и сдвоявай от екрана
  *„Add device"* на Bluetooth-а (не от главния списък).
